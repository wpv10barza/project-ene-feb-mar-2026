# project-ene-feb-mar-2026

Código fuente recuperado de Google Drive y clasificado para enero, febrero y marzo de 2026.

## Proyectos

- `SistematizadorEntrevistas/` — automatización Selenium + SQL para sistematización y carga de resultados.
- `clawd/` — workspace documental de agente.
- `agent_text/` — agente de voz en modo texto con Whisper.
- `gemini_fix/` — exportación de contenido de Gemini a Word mediante Selenium.

Se excluyeron `.git`, entornos virtuales, cachés, datos generados y archivos con credenciales.
